# Project AI Context

This directory contains **project-specific context only**.

The reusable AI workflow is intentionally not stored in this repository.

Canonical reusable workflow:

`szymoniwacz/ai-project-template`

Integration entrypoint:

`bin/ai-workflow`

## Rule

Do not copy reusable workflow files, prompts, policies, contracts, review rules, orchestration, or shared conventions from the private workflow into this directory.

Use this directory only for facts and constraints that belong to the target project itself.
